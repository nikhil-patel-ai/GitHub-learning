## Learning Approach

- Each official topic has exactly one numbered notebook.
- Related material from earlier lessons has been integrated into the relevant official topic notebook rather than kept as separately named supplementary files.
- Notebooks use concise explanations, key terminology, practical commands, verification guidance, common mistakes, exercises, interview questions and summaries.
- Practice commands in the separate `git-practice-project` repository, not in this learning-notes repository.
- Actual terminal output should be recorded only after the exercise has been run.
