# Git Initialization & Command Practice

## Overview

This repository contains hands-on exercises for learning and practising essential Git commands. It provides a simple environment to understand how Git tracks changes, stages files, and manages project history.

## Learning Objectives

- Understand Git repository initialization.
- Check repository status using `git status`.
- Stage changes using `git add`.
- Save changes with `git commit`.
- Compare file changes using `git diff`.

## Commands Practised

| Git Command | Purpose |
|---|---|
| `git init` | Initialize a new Git repository |
| `git status` | Check the current repository status |
| `git add` | Stage changes for the next commit |
| `git commit` | Save staged changes in repository history |
| `git diff` | Compare changes between file versions |

## Practice Files

| File | Description |
|---|---|
| `new-name.txt` | File used for Git file-management practice |
| `notes.txt` | File used for practising Git changes |

## Learning Approach

Each exercise focuses on understanding Git commands through practical execution, observing repository changes, and reviewing command outputs.

## Repository Purpose

This repository is part of my Git & GitHub learning journey. It documents practical exercises and helps build confidence in using Git for version control.
