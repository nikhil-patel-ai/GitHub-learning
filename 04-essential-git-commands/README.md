# 04 - Essential Git Commands

## Overview

Learn essential Git commands for repository initialization, file tracking, commits, history inspection, and undoing changes.

## Learning Objectives

- Initialize and manage Git repositories.
- Track, stage, and commit changes.
- Inspect commit history and file differences.
- Rename and remove tracked files.
- Restore files and undo changes safely.
- Understand Git reset, revert, and clean.
